# 点描トレーサー (Stipple Tracer)

画像を1枚渡すと、その形をなぞる「光の点描画」としてSVGを生成するツールです。
写真が無くても、白紙に描いた下絵からそのまま点描を起こせます。
消しゴム・追加ペン・星座線での手直しにも対応しています。外部ライブラリへの依存はなく、
アプリ本体は `index.html` 1枚で完結します（ほかはアイコンなどの小さなファイルだけ）。

## できること

- **画像から点描を起こす** … ドラッグ&ドロップした画像の濃淡と輪郭をなぞって点を打つ
- **下絵から起こす** … 「白紙にする」で真っ白な台紙を出し、筆・直線・円・四角・消しゴムで
  下絵を描く。写真の上に描き足すこともできる。線はベクタで持っているので「一つ戻す」が効く
- **手直し** … 消しゴム／追加ペン／星座線。自動での星座線つなぎも可能
- **光り方を作り込む** … 暈と芯を別々の色・にじみ・不透明度で調整、加算合成、ゆらめき
- **同じ絵を再現できる** … 点の配置は乱数の種から決まる。設定を戻せば同じ点が戻ってくる。
  総入れ替えしたいときだけ「再生成」を押す

姉妹アプリ **RONDO 時の座標**（`ym-rondo/rondo-cosmos`）に絵を載せるための機能もあります。

- **「RONDOの光」** … 押すとRONDOの3D空間と同じ光り方に一括で揃う
- **「RONDOへ渡す」** … 種類とバリアントを選んで、SVGコードや
  `layout.json` 用のJSONをクリップボードにコピーする
- **「連作」** … 一年の区分名（12個＋編成月）のように何個も作るとき、
  1つずつスロットに溜めて、最後にまとめて1つのJSONに書き出す

RONDO 側の事情は [RONDO連携メモ.md](RONDO連携メモ.md) にまとめてあります。

## ローカルで確認する

ビルド不要です。`index.html` をブラウザで直接開くだけで動きます。

```bash
open index.html   # macOS
# または index.html をダブルクリック
```

## Vercelに公開する(GitHubなし・一番早い方法)

1. https://vercel.com にログイン(GitHubアカウントでのログインも可)
2. ダッシュボードの「Add New...」→「Project」
3. 「Deploy without Git」のような案内が出るので、この `stipple-tracer-repo` フォルダごと
   画面にドラッグ&ドロップ
4. そのままデプロイすれば、数十秒で公開URLが発行されます

## GitHub経由でVercelに公開する(あとで更新しやすい方法)

1. https://github.com で新しいリポジトリを作成(例: `stipple-tracer`)
2. リポジトリ画面の「Add file」→「Upload files」で、この中の
   `index.html` と `README.md` をドラッグ&ドロップしてコミット
   (ターミナルの `git` コマンドを使わなくても、ブラウザだけで完了します)
3. https://vercel.com の「Add New...」→「Project」→「Import Git Repository」で
   今作ったリポジトリを選択
4. Framework Preset は "Other"(静的サイト)のままでOK。ビルドコマンドやOutput
   Directoryも空欄で問題ありません
5. 「Deploy」を押せば公開されます。以後はGitHubリポジトリを更新するたびに
   Vercelが自動で再デプロイします

## 保存ボタンについて

「SVGを保存」ボタンは、Claudeのアーティファクトとして開いている場合はその場で保存確認が出ますが、
Vercel等の通常のWebサイトとして公開した場合は、ブラウザの通常のダウンロードとして
`stipple.svg` が保存されます(どちらの環境でも動くように作ってあります)。

## ファイル構成

```
index.html            アプリ本体(HTML/CSS/JS 全部入り)。外部の読み込みはGoogle Fontsのみ
README.md             このファイル
RONDO連携メモ.md      姉妹アプリ RONDO 側の事情と、絵の受け渡し方の引き継ぎメモ
icon.svg              タブ用アイコン(点描の三日月)
apple-touch-icon.png  iOSでホーム画面に置いたときのアイコン(180px)
icon-192.png          Androidでホーム画面に置いたときのアイコン
icon-512.png          同上(大きいほう)
site.webmanifest      ホーム画面に置いたときの名前とアイコンの指定
makeicon.js           アイコンを作り直すスクリプト(サイトには関係しない)
```

アイコンは手描きではなく `makeicon.js` が計算で描いたもので、絵柄はアプリを開いたとき
最初に出る三日月そのものです。作り直したいときは点の数・色・寸法を変えて
`node makeicon.js` を走らせると、PNGとSVGが同時に出し直されます。

## ブラウザに保存されるもの

- `stipple-tracer:presets:v1` … 名前を付けて保存した設定
- `stipple-tracer:rondo-slots:v1` … 連作スロット（下絵・設定・書き出し用SVG）

どちらもこのブラウザの中だけに残ります。別の端末へ移すときは、設定は
「書き出す」、連作は「まとめてコピー」でファイル／テキストにしてください。
